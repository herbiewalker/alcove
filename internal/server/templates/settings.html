Allowed networks

Requests from anywhere else are refused. {{.AllowedSource}}

For example 192.168.1.0/24. Your own address is {{.YourIP}}; keep it covered. A change must be confirmed within a minute or it undoes itself.

Reverse-proxy mode

Use this when Caddy, Nginx Proxy Manager or tailscale serve sits in front and provides HTTPS. Forwarded addresses are believed only from the proxies listed. {{.ProxySource}}

Require HTTPS

Refuse sign-ins over plain HTTP. It can only be switched on from an encrypted connection, so you cannot lock yourself out. {{.TLSSource}}

Default time zone

Used for anyone who has not set their own on their profile. It decides which day an entry falls on and the times shown. Stored data is never changed. Now in use: {{.DefaultTZ}}.

A name like America/New_York or Europe/Berlin. Saved here, it is kept even if the container's settings are reset. Empty goes back to the container's setting ({{.ZoneFallback}}).
